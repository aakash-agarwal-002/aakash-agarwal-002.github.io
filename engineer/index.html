About Me

I am an AI/ML engineer and MS by Research graduate in Computer Science from IIT Bombay, with 4+ years across software engineering and applied AI. I build LLM, multimodal, and machine learning systems: fine-tuning and post-training, evaluation harnesses, agentic workflows, and data pipelines, using PyTorch, Hugging Face, LangGraph, FastAPI, Docker, and SQL.

I built HyperLoRA, a PyTorch system that generates per-shard LoRA adapters on the fly, so a data shard can be removed from a model in O(1) time with the base model frozen. Its deployable router scores 0.80 AGG on TOFU, against 0.81 for a full retrain and 0.53 for the strongest tuned post-hoc baseline.

As an AI/ML Engineer Intern at Fujitsu Research, I built multi-stage LLM workflows with LangChain and LangGraph, cut agent inference latency from 18s to 10s, and ran an MLflow-tracked evaluation harness over 2,400+ runs. Before my MS, I spent two years as a Software Developer at Accenture shipping backend features in Python and SQL.
